# Video demos

Each demo runs about 90 seconds and has English captions. Every number
on screen comes from a real run of the package. To watch on YouTube, use
the links under each video.

## Workbench tour

example, explore it, let the workbench compare the Rasch, 2PL and 3PL
models, read the plain-language results, open the Wright map and an item
health card, and download the report and the R script.
