# Open a lab in the browser

Runs a lab folder with
[`learnr::run_tutorial()`](https://pkgs.rstudio.com/learnr/reference/run_tutorial.html)
so you can try it as a student would. Run
[`check_material()`](https://www.okanbulut.com/mirtverse/reference/check_material.md)
first to catch errors quickly.

## Usage

``` r
preview_lab(lab, ...)
```

## Arguments

- lab:

  the lab folder.

- ...:

  passed to
  [`learnr::run_tutorial()`](https://pkgs.rstudio.com/learnr/reference/run_tutorial.html).

## Value

Nothing useful; called for its side effect.
