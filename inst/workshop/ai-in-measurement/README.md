# AI in measurement: A one-day workshop

A workshop kit for psychometricians, testing-program staff and graduate
students who know item response theory (IRT) and some R, and want to judge
and use artificial intelligence (AI) in their work. Made with the
mirtverse R package.

| File | What it is |
|---|---|
| `slides.Rmd` | The slides for the day (an ioslides presentation). Render with `rmarkdown::render("slides.Rmd")` and open `slides.html` in a browser. |
| `facilitator-guide.Rmd` | The facilitator's guide: Preparation, the schedule, what to say and ask in each session, and what to do when something goes wrong. Render it the same way, or read it as text. |
| `README.md` | This file. |

Participants need R, the mirt, mirtverse and learnr packages, and nothing
else: The labs and examples run offline from simulated data and recorded
language-model answers. No API key is needed.

Edit the slides freely: Put in your own program's examples, drop a
session, or swap a lab. The answer keys for the labs are in the
"Teaching labs" article on the mirtverse site, under "Answer key".
